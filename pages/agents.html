Architecture

4-agent pipeline.
Zero manual steps.

🔍
Prospector

Finds real businesses from OSM, Google Places, Apollo, Hunter. MD5 deduplication across all sources.

🎯
Scorer

GNN spatial scoring + AI enrichment. Scores leads 1–10 with fit score, pain points, icebreaker.

✍️
Writer

Generates personalized email + WhatsApp per lead. LLM-as-Judge evaluates on 5 dimensions before send.

📤
Delivery

Sends via SendGrid + Gupshup. Auto-schedules Day 3 and Day 7 follow-ups via Celery.

Infrastructure underneath: Each agent communicates via Redis queues with per-job isolation. If the Writer fails mid-job, the Prospector's work is not lost — state is persisted in PostgreSQL. This is the Orchestration Layer in production.

🧠 AI Techniques Implemented
  • OPRO — self-optimizing prompts. Tracks reply rates per prompt version, uses LLM to evolve better prompts weekly. Diversity score prevents prompt collapse.
  • Reflexion — failure learning. Agent tracks what went wrong and adjusts behaviour automatically.
  • MemGPT — tiered memory. Working memory, episodic, long-term. Full conversation memory per lead.
  • ReAct — reasoning traces. Agent explains its decisions before acting.
  • LLM-as-Judge — 5-dimension evaluation (personalization, cultural fit, CTA strength, tone, clarity) before every send.
  • RAG — dynamic few-shots from historical high-performing messages.
  • A/B Testing — framework for comparing prompt and message variants.
⚡ Infrastructure Problems Solved
  • Multi-source deduplication — MD5 fingerprint hashing name + company + email + phone prevents duplicates across 4 sources and across agent runs.
  • Async multi-agent pipeline — 4 agents communicate via Redis queues with per-job isolation. Partial failure recovery — Prospector's work survives Writer failure.
  • GNN spatial scoring — businesses modeled as nodes in a spatial graph. Geographic demand patterns and business clustering produce dramatically better lead quality than flat-list scoring.
  • LLM self-optimization without collapse — OPRO implementation maintains diversity score across active prompt versions to prevent all prompts converging to one style.
